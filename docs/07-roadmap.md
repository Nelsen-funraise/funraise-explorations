# 07 · 路線圖：0 → 24 個月（含停損條件）

> 原則：先用最少的工程證明「畫面會賣」，再用設計夥伴把畫面變成合約，最後才擴全國與平台化。每一階段都有明確的「不繼續」條件。

## 階段 0（第 0–6 週）：Wow Demo
**目標**：一個能在 All Hands、遠雄、一家壽險、政大面前 15 分鐘講完的真 3D、真資料、真語音 demo。
- Fork GEV，加 `taipei` 城市 POI、關閉與台灣無關的圖層（飛機／船／衛星留一個當彩蛋）。
- 用 `gods-eye-view/infrastructure` 掛四層 FUNRAISE 資料：商辦存量（擠出）、都更單元（多邊形）、建照／未來開發（幽靈建物＋完工年）、MOPS 交易（脈衝）。資料由 FUNRAISE MCP 經 server provider 轉接。
- 語音先沿用 GEV 的 OpenAI Realtime 路徑（zh-TW），新增 6 個工具：set_lens／set_year／query_mcp（通用 MCP 轉呼）／show_provenance／export_memo／open_pickpeak。
- Provenance HUD 第一版：每次工具呼叫顯示工具名、筆數、資料期間。
- 本 repo 的 Canvas 原型作為互動腳本與 UX 規格（鏡、指令、視角）。
**產出**：Demo 影片 90 秒、三場客戶預覽、內部 All Hands。
**停損**：三場預覽中少於兩場表達「願意付費或共同開發」→ 回到 PickPeak 內嵌小型化版本（僅接待中心牆）。

## 階段 1（第 2–4 個月）：開發商鏡 × 接待中心牆 × 學研啟動
- 遠雄一個案場裝機（4K 大屏、平板遙控、語音）；導覽腳本（Scene）：基地→捷運與公共建設完工年→周邊供給 2028→商圈行情→都更。
- 開發商鏡功能：分區與容積即問即答、都更進度、競品建照、土地邊界（地籤）。
- 時間軸 2012→2030 上線（GEV 沒有的核心差異）。
- 學研：政大地政課程試用；AI Raiser 第三屆主題「為睿鏡做一個 Skill」。
- 資料新鮮度：每層 `data_as_of` 與 `promised_cadence`，HUD 顯示。
**產出**：第一筆裝機合約、第二個案場 pipeline、課程回饋、Skill ×5。
**停損**：裝機後 60 天內業務不主動用（週使用 < 3 次）→ 改成銷售人員手上的平板版而非大屏。

## 階段 2（第 4–9 個月）：投資人鏡 × 雷達 × 公眾版
- Deal Radar／Move Radar 訂閱：守備範圍、每日簡報、LINE／Teams 推播；先賣商仲店東與 39 家生態系夥伴。
- 投資人鏡：租金收益率、供給壓力、DD memo（Voice DD）；一家壽險設計夥伴 → Portfolio Twin 年約。
- Agent 運行時第二版：推理與工具編排改由 Claude 承擔，語音層抽離可換供應商；Map-as-a-Tool 回傳可分享地圖連結給 MCP 用戶。
- **公眾版「台灣天眼」於 RAISE DAY 2027（1 月）發表**：免登入、今日成交／都更／開工／法人交易、語音問答、時光模式；媒體合作每週素材。
- Taiwan Live MCP 開源：TDX、氣象、空品、CCTV。
**產出**：雷達訂閱 100+ 範圍、投資人鏡 30+ 席、壽險年約 1 家、公眾版首月 10 萬不重複訪客（目標）。
**停損**：公眾版首月 < 2 萬訪客且無媒體引用 → 停止公眾版投入，資源回到 B2B 鏡。

## 階段 3（第 9–18 個月）：城市治理 × 全國 × 行動
- 城市治理鏡：一個局處或住都中心試點（DIGITAL+／智慧城市案），政大共同提案；首長戰情室大屏。
- 七都擴張：工業與廠辦鏡先行（產業園區、公司登記在中南部最完整）；國土署 3D 建物作為 Google 3D 未覆蓋區域的底圖。
- 現勘鏡（手機 AR）：對準大樓出地號／分區／歷史成交；估價師與銀行鑑價流程（第一太平戴維斯、台新）。
- 企業私有部署（Portfolio Twin 第 2–3 家）。
**產出**：政府案 1 件、七都上線、現勘鏡 500 MAU、企業版 3 家。

## 階段 4（第 18–24 個月）：平台
- Lens Marketplace：夥伴資料封裝成 MCP 工具、在睿鏡販售、抽成。
- 嵌入式睿鏡（建商官網、商仲物件頁、媒體）與 API。
- 評估海外（日本／東南亞）是否複製「開放資料 × MCP × 上帝視角」模式——僅在台灣 ARR 站穩後。

## 團隊與預算（第一年）
- 核心 7 人：前端／3D ×2、Agent／工具 ×2、資料（PI 團隊既有）×1、設計 ×1、PM ×1；由 Experience（CXO）組織承接，Data（CTO）組織提供 MCP 與資料，BizPeak 團隊承接 Voice Agent 與 LINE 推播的共用元件。
- 變動成本：3D tiles session、語音分鐘、模型 token；以每個付費方案內含額度控管。
- 補助：DIGITAL+（最高 1,500 萬／2 年）以城市治理鏡＋Taiwan Live MCP 開源申請。

## 與現有產品的關係
- **PickPeak**：睿鏡是 PickPeak 的「高點視角」入口與 3D 大樓詳情的下一代；PickPeak Solutions（謄本清冊、都更、搬遷地圖、產權）成為鏡裡的輸出物。
- **BizPeak**：接待中心牆與雷達是 BizPeak「Studio／Insight」可交付的產品；Voice Agent 共用語音層；LINE Chat 是雷達的推播通路。
- **FUNRAISE MCP**：不動一行資料工具；睿鏡是最大的呼叫來源、最好的銷售員，也是 MCP 第三階段（夥伴資料封裝）的展示場。
