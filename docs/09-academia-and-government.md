# 09 · 學界與政府：從關係到槓桿

## 1. 為什麼學研要從第一天開始
- **便宜、快、可信**：課程與研究授權幾乎零邊際成本；一個學期就能拿到 30–60 位使用者的真實回饋與論文級的方法驗證。
- **資料槓桿**：TGOS 的地籍圖、地址、土地利用調查等 API 僅開放公部門／國營／學研；在共同研究框架下，學術夥伴能合法取用、共同產出方法與成果（不直接商用，但能校準我們的自有資料）。
- **人才漏斗**：AI Raiser 先鋒計畫已證明「學員做 Skill 上傳 MCP」模式；政大地政、台大城鄉的學生就是下一屆 Raiser 與未來客戶（壽險、建商、政府）的種子。
- **公信力**：城市治理鏡進入政府時，政大地政系的共同提案比任何業務簡報都有效。

## 2. 具體方案

### 2.1 政大地政 × 睿鏡「都市再生時光實驗室」
- 對象：白仁德老師團隊、都市再生論壇。
- 內容：以 2012–2030 時間軸研究都更／危老對周邊成交價與租金的前後效果；學生用睿鏡做期末專題（每組一個行政區的「更新敘事」），最佳專題在 RAISE DAY 展出。
- 我們得到：方法論（可寫進 DD memo 的「都更影響」章節）、對照組資料校準、政府提案背書。
- 授權：課程免費；研究成果共同發表；學術 API 取得的圖資僅用於研究。

### 2.2 台大城鄉／建築與城鄉「城市駕駛艙工作坊」
- 內容：TOD 站區（環狀線、民生汐止線）開發前瞻工作坊，學生用城市治理鏡做站區供給與人流敘事；產出交給捷運局／都發局作為對話素材。
- 我們得到：城市治理鏡的真實使用腳本與政府對話入口。

### 2.3 北大不動產／估價師學會「Voice DD 認證課」
- 內容：用睿鏡與 FUNRAISE MCP 做一份可回查的估價前置備忘錄；與第一太平戴維斯估價案例智慧管理系統經驗接軌。
- 我們得到：估價師社群的採用與口碑（銀行鑑價通路的鑰匙）。

### 2.4 AI Raiser 第三屆：「為睿鏡做一個 Skill」
- 學員任務：把一個真實工作流做成語音可觸發的 Skill（例：「幫我做搬遷比較」「列出這個園區的增資公司」）。
- 黑客松評審邀請政大、台大老師與一家壽險。

## 3. 政府：先補助、再試點、後採購
- **數位產業署 DIGITAL+**（最高 1,500 萬／2 年）：以「城市治理鏡＋Taiwan Live MCP 開源」申請；亮點是開放資料的 agent 化與可回查敘事。
- **產業發展署**：工業與廠辦鏡（產業園區進駐率、企業遷入遷出）對接招商與園區管理需求；中南部擴張的第一個政府夥伴。
- **縣市層級**：都發局／地政局（都更與地籤）、捷運局（TOD）、住都中心（公辦都更標案：MOPS 中「公部門單位」賣方的案件正是他們的）。
- **首長戰情室**：以「捷運完工前後周邊變化」「產業遷入地圖」兩個敘事切入；大屏＋語音＋導覽腳本正是 GEV 的 Scene director 用法。
- 注意事項：政府資料的引用要標註來源與版本；公開畫面避免對特定個案做價格預測；採購週期長，第一年不列為主要營收。

## 4. 學界與政府共用的產品能力
- 學研鏡：唯讀、匿名匯出、Notebook 範例、可重現腳本。
- 城市治理鏡：前後對照（before／after）視圖、政策圈選範圍、議會答詢卡。
- 兩者共用時間軸與 Provenance HUD——這也是對外說明「AI 不是黑箱」最好的教材。

1. 與白仁德老師敲定 2027 春季課程使用（10 月前）。
2. 提交 DIGITAL+ 申請書草稿（含 Taiwan Live MCP 開源承諾）。
3. 邀請一位台大城鄉老師、一位估價師學會理監事加入階段 0 的三場預覽之一。
4. AI Raiser 第三屆主題定為睿鏡 Skill。
