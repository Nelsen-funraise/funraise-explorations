## 1. 收入結構（五條線，同一底座）

**12 個月粗估**：A 約 2,000–5,000 萬、B 約 1,000–2,000 萬、C 約 1,500–4,000 萬、D 約 500–2,000 萬、E 約 300–1,000 萬 → 合計 NT$ 5,000 萬–1.4 億 ARR 等值。這是假設，不是預測；第一季的設計夥伴訪談會把區間收窄。

## 2. 為什麼這次能「一舉打開市場」

1. **可見度**：GEV 用三個月拿到 3.2 萬星，證明「即時上帝視角」的畫面本身就是媒體。台灣沒有人做過「今天誰買了哪棟樓、哪裡在都更、2028 年天際線長什麼樣」的即時公開畫面。公眾版對準 RAISE DAY 2027（1 月）一次引爆。
2. **買單者已在名單上**：遠雄（接待中心）、台新（BizPeak 客戶，銀行鑑價與分行選址）、第一太平戴維斯（估價師 DD）、39 家生態系夥伴（Move Radar 名單）、政大（學研）、壽險／REITs（MCP GTM 第二階段就鎖定的客群）。
3. **獨家層**：資本流（MOPS）＋企業遷徙（公司登記異動）＋供給前瞻（建照／未來開發）＋時間軸（2012–2030）。這四層在台灣沒有第二家能同時提供。
4. **成本結構有利**：底座是開源（MIT）、資料已在 MCP、模型成本可控（voice 每分鐘數美分、3D tiles 按 session 計量）；第一年主要成本是 6–8 人的產品工程與設計。

## 3. 進入市場順序

### 第一波（0–4 個月）：設計夥伴 × 三個鏡
- **開發商鏡**：遠雄（已是客戶）→ 一個接待中心裝機試點；目標：兩個案場付費。
- **投資人鏡**：一家壽險或 REITs 投資部做 Deal Radar 設計夥伴（免費 3 個月換每週回饋與 case study）。
- **選址鏡**：PickPeak 既有活躍用戶（約 3 千／季）直接升級體驗；商仲租賃團隊席位試賣。
- **學研鏡**：政大地政白老師課程用睿鏡上課；學生 Skill 回饋 MCP。
- 內部：AI Raiser 第三屆主題直接定為「幫睿鏡做一個 Skill」。

### 第二波（4–9 個月）：把畫面變成生意
- 公眾版「台灣天眼」上線（RAISE DAY 2027）＋媒體合作（一家財經媒體每週用睿鏡畫面做「本週資本地圖」）。
- Move Radar 對 39 家生態系夥伴開賣（搬家、傢俱、清潔、裝修：「增資＋搬遷＝要裝修、要搬家、要買傢俱」）。
- 城市治理鏡：以 DIGITAL+ 或縣市智慧城市案切入一個局處；政大共同提案。
- Portfolio Twin：第一家壽險簽年約。

### 第三波（9–18 個月）：全國與行動
- 七都擴張（工業與廠辦鏡打頭陣，資料在中南部最完整）。
- 現勘鏡（手機 AR）給房仲與估價師；台新／銀行鑑價流程整合。
- Map-as-a-Tool：MCP 用戶在 Claude／ChatGPT 裡一句話開地圖。

### 第四波（18–24 個月）：平台
- Lens Marketplace：夥伴資料封裝成 MCP 工具、在睿鏡販售。
- 企業私有部署；API 與嵌入式睿鏡（建商官網、商仲物件頁）。

## 4. 通路與夥伴

- **直銷**：現有 BD／商機開拓小組；接待中心牆由建商 BD 帶；壽險由 CEO 關係帶。
- **生態系**：39 家夥伴既是客戶也是通路（他們的業務到每個客戶辦公室）。
- **學界**：政大地政（白仁德老師、都市再生論壇）、台大城鄉；學術身分可申請只開放學研的 TGOS 地籍圖等 API 於共同研究。
- **政府**：產業發展署、數位產業署 DIGITAL+（最高 1,500 萬／2 年）；縣市智慧城市與都更主管機關。
- **媒體**：數位時代、今周刊已報導 FUNRAISE；公眾版是他們每週要的「資料視覺化素材」。

## 5. 定價原則
- 以「鏡」定價、以「守備範圍」計量、以「裝機」收一次性——三種節奏對應三種買方預算科目（人事席位、行銷、資本支出）。
- 每個付費方案都內含 MCP 呼叫額度；超額計量，讓睿鏡使用直接反映在 MCP 北極星上。
- 學研永遠便宜或免費：它換的是資料、人才與公信力。

## 6. 指標（北極星與護欄）
- 北極星：**FUNRAISE MCP 月工具呼叫量**（其中來自睿鏡的比例）。
- 商業：付費鏡席位數、天眼牆裝機數、雷達訂閱範圍數、企業版年約數、NRR。
- 體驗：語音指令成功率（≥ 85%）、回答附來源率（100%）、資料新鮮度 SLA 達成率（每層時間戳與承諾更新頻率的一致性）。
- 品牌：公眾版分享數、媒體引用次數、RAISE DAY 現場轉換率。
