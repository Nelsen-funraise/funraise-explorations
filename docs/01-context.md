## 3. God's Eye View（GEV）到底證明了什麼

- **開源、爆紅、可複製**：2026-06-22 建立，到 2026-09-14 已 31,968 stars／6,419 forks，程式碼約 24 萬行（含 232 個單元測試），MIT 授權（資料另計）。
- **技術棧務實**：無框架 ES modules ＋ Vite 6 ＋ CesiumJS 1.124 ＋ Google Photorealistic 3D Tiles；語音為 OpenAI Realtime（gpt-realtime-2），28 個 function tools；鏡頭由模型透過工具間接控制（fly_to／move_camera／track_entity／annotate_map／analyst_query…）。
- **體驗公式**：即時圖層（飛機、船、衛星、火災、CCTV、電台、單車）× 語音 × 多視角（Globe／Cockpit／Street／Orbital／Detection）× 感測風格（CRT／夜視／熱像…）× 五字 AI HUD 摘要。作者原話：「一半的魔法是它看起來像禁忌的駕駛艙，另一半是每一行程式碼都可檢視。」
- **它沒有的**：**時間軸**。作者明說「現在是便宜的部分；回到過去才是資料與算力的殘酷之處，那是長期遊戲」。GEV 也沒有多邊形產權、法規、資本流等「土地經濟」層。
- **可直接借用的擴充點**：`src/layers/<name>/` 圖層慣例；`gods-eye-view/infrastructure` 套件可直接吃 GeoJSON＋metadata（Datacenters／Dams 就是這樣做的）→ **我們的多邊形與建物層不必自寫渲染**；`server/providers/*` 代理層可放 MCP 轉接；`CITY_POIS` 加 Taipei；工具 enum 要同步改三處。
- **商用地雷**：Cesium ion Community 僅限非商用（要走 Google 直接計量金鑰）；海纜資料 CC BY-NC-SA 必刪；OpenSky／Esri／Google News 授權需審視；voice 每分鐘數美分且有 5 美元/場上限；作者團隊（Halfpixel）正在做閉源託管版。

## 4. 台灣市場與競局（摘要，細節見附錄）

- **量體**：2025 年全台買賣移轉 26.1 萬棟（9 年新低）；商用不動產＋土地成交 3,235 億（CBRE）；2026 上半年商用投資 1,266 億（年增 92%）；危老申請 2025 年前 11 月 683 件（年增 1.4 倍）。
- **住宅端對手**（樂居、591、好時價）：免費／低價 C 端，實價查詢與估價；**沒有商用深度、沒有 agent 介面**。
- **商用端**（CBRE／JLL／高力／戴德梁行／信義全球資產）：PDF 季報、人工彙整、**非即時、非 API**。
- **國際對標**（Esri GeoAI、Palantir、CoStar、Reonomy、Cherre、Placer.ai）：皆無台灣在地資料；CoStar 年費中位數約 4 萬美元、Reonomy 每席 400–575 美元/月，證明「地產情報席位」有價。
- **政府 API**：TDX（運輸即時）、氣象署（即時）為真即時；實價登錄、都更、建照為批次；國土署 3D 圖臺已有 539 萬棟 3D 建物（I3S／3D Tiles）；TGOS 地籍圖 API 僅開放公部門／學術 → **學界合作是資料取用的槓桿**。
- **空白地帶**：沒有任何產品同時具備「台灣在地資料深度 × 即時 × 3D × 語音 × 時間軸 × Agent 可調用」。

## 5. 一句話結論

> GEV 把「現在」做成了開源商品；FUNRAISE 擁有「過去」與「未來」。把兩者接起來，就是台灣第一個能讓人一眼看見城市如何被買賣、被更新、被建造、被遷入的 Agent Native 產品。
