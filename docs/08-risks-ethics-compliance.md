## 2. 倫理邊界（沿用並強化 GEV 的宣言）
- **不做具名個人搜尋、人臉辨識、個人追蹤**。CCTV 僅用政府公開的交通影像，不做人形辨識。
- **謄本**：預設二類（去識別化）；一類謄本僅在客戶具法定權限且用戶自行調閱時，於其私有工作區處理，不進入共享圖層。
- **公司登記與 MOPS**：法人公開資料；自然人買賣方一律以類型（「自然人」）呈現，不顯示姓名。
- **實價登錄**：依內政部揭露規範（門牌／樓層去識別化），不做反向推論個人持有。
- **敏感區域**：軍事、外館、機關周邊不提供街景鏡細節放大（可設定遮罩清單）。
- **估價與投資建議**：睿鏡提供資料與可回查敘事，不提供投資建議；所有估計值標示「RECONSTRUCTED ESTIMATE／推估」。

## 3. 授權清單
- **程式碼**：GEV MIT（資料另計）。刪除 `telegeography_submarine_cables`（CC BY-NC-SA）；關閉 OpenSky、AISStream、FIRMS、Esri 等與台灣產品無關的來源，或在啟用前逐一確認商用條款。
- **底圖**：Google 3D Tiles（商用條款、直接金鑰）；OSM（ODbL，需標註）；國土測繪中心 WMTS／3D 圖臺（依其使用規範，商用需確認）。
- **政府開放資料**：政府資料開放授權條款（可商用、需標註）。實價登錄、都更、建照、公司登記、MOPS 皆屬此類；TGOS 部分 API 僅開放公部門／學研（透過學術合作於研究範圍使用，不直接商用）。
- **FUNRAISE 加值層**：PI 團隊清洗、比對、模型與知識庫為自有資產；MCP 條款延伸至睿鏡。
- **夥伴資料**（Marketplace）：由夥伴授權、標註來源與期間、可下架。

## 4. 個資與資安
- 瀏覽器只持短效 token；供應商金鑰留在伺服器（GEV 模式）。
- 私有圖層（Portfolio Twin）以租戶隔離或私有部署；查詢日誌保留供稽核（MCP 團隊方案已有 SSO／稽核）。
- 語音錄音不留存（僅即時轉寫）；轉寫文字依客戶設定保留期限。
- 與個資法對齊：法人資料為主；涉及自然人的欄位一律去識別化或類型化。

## 5. 最大的單一風險與我的判斷
最大的風險不是技術，而是**把它做成「又一個平台」**。睿鏡要成功，必須從第一天就是「賣得出去的畫面」（接待中心牆、雷達）與「講得出來的故事」（公眾版、RAISE DAY），而不是功能清單。因此路線圖把商業化放在第 4 個月，把公眾版放在 RAISE DAY，把全國與平台放在後面。
