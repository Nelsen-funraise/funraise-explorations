# 00 · 執行摘要：睿鏡 PeakLens — 台灣不動產的 Agent Native 上帝視角

**給**：Nelsen（CXO）、四位共同創辦人 · **日期**：2026-09-14 · **狀態**：策略提案 v1 ＋ 可互動原型

## 一頁結論

1. **機會**：God's Eye View（GEV）三個月拿到 3.2 萬顆星，證明「即時、相片級 3D、語音、多視角」的地理情報體驗已是開源商品；但它只有「現在」，作者明言「回到過去才是長期遊戲」。FUNRAISE 擁有的正是它沒有的：2012 年起的實價登錄、到 2030 年的建照與開發 pipeline、都更圖形、資本流（MOPS）、企業遷徙（公司登記異動）——而且已經是 30+ 個 MCP 工具。
2. **產品**：**睿鏡 PeakLens**（代號）——你對城市說話，地圖就回答，每個答案都能回溯到一個 FUNRAISE MCP 工具呼叫與資料期間。一個底座、五個「鏡」（投資人／開發商／企業選址／城市治理／學研），鏡即產品、鏡即定價。核心差異是 **Present × Past × Future 三軸同框的時間軸**與**可回查的敘事（Provenance HUD）**。
3. **怎麼賣**：先賣有預算科目、且已認識我們的客戶——**建商接待中心天眼牆**（遠雄）與 **Deal／Move Radar 訊號訂閱**（商仲店東、39 家生態系夥伴）；第二波用**公眾版「台灣天眼」**在 RAISE DAY 2027 引爆認知，帶動 MCP 試用；接著 **Portfolio Twin**（壽險／REITs 年約）與**城市駕駛艙**（DIGITAL+ 補助、政大背書）。學研鏡從第一天做，成本最低、槓桿最大（人才、資料取用、公信力）。
4. **怎麼做**：fork GEV（MIT），用它的 `infrastructure` 套件直接吃我們的 GeoJSON＋屬性，相機與標註工具照用；Agent 運行時以 Claude 編排 FUNRAISE MCP＋GEV 工具＋Lens 工具，語音層可換；新增時間軸與 Provenance HUD。**不動任何資料工具**，睿鏡成為 MCP 最大的呼叫來源與最好的銷售員。
5. **多少、多快**：7 人核心小組；第 6 週 Wow Demo（三場客戶預覽，少於兩場願付費即停損）；第 4 月第一筆裝機合約；2027-01 公眾版；第 12 月五鏡皆有付費標竿客戶、ARR 等值目標 5,000 萬起（假設區間，見 05）。
6. **最大風險**：做成「又一個平台」。因此路線圖把可收費的畫面（牆、雷達）放在第 4 個月、把故事（公眾版）放在 RAISE DAY、把全國與平台放最後；資料新鮮度做成產品功能而非口頭承諾。
